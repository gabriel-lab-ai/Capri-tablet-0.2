# Capri for tablets (web app)

A browser can't float over other apps, so on a tablet she lives inside this app.

1. Put this folder on any web host (Netlify Drop, GitHub Pages, Cloudflare Pages), or run `python3 -m http.server`
   on a computer on the same Wi-Fi and open http://<computer-ip>:8000 on the tablet.
   (Installing to the home screen needs https or localhost.)
2. Open the page on the tablet > browser menu > Add to Home Screen. She opens full screen.
3. Tap the orb. Type `/key YOUR_ANTHROPIC_KEY` once to give her a brain (saved only in that browser).
